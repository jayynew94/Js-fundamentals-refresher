How to Run
Make sure you have Node.js installed, then:
bash# Clone the repo
git clone https://github.com/YOUR_USERNAME/js-fundamentals-refresher.git

# Navigate into the folder
cd js-fundamentals-refresher

# Run any file
node practice.js
node functions.js
node arrays.js
